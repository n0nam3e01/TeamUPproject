# TeamUP — бот для сбора на школьные игры

Телеграм-бот, который помогает ученикам одной школы собираться на спортивные игры
после уроков. Любой создаёт игру (спорт, день, время, место, сколько нужно человек),
остальные видят её в списке и записываются одной кнопкой. Когда народу набралось
сколько нужно — всем приходит «команда собрана», а за час до начала — напоминание.

Всё работает на твоём компьютере. Никаких сайтов, оплат и облаков.

---

## Что нужно сделать один раз

### Шаг 1. Получить токен бота

1. Открой Telegram и найди бота **@BotFather**.
2. Отправь ему команду `/newbot`.
3. Он спросит имя бота — напиши, например, `TeamUP`.
4. Потом спросит адрес — он должен заканчиваться на `bot`, например `teamup_school_bot`.
   Если такой уже занят — придумай другой.
5. В ответ придёт длинная строка вида `7123456789:AAH...` — **это и есть токен**.

> Токен — как пароль от бота. Никому его не показывай и не выкладывай в интернет.
> Если случайно показал — напиши @BotFather команду `/revoke`, он выдаст новый.

### Шаг 2. Узнать свой telegram id

Найди в Telegram бота **@userinfobot** и напиши ему что угодно. Он пришлёт твоё число
(например, `512345678`) — это `ADMIN_ID`. Он нужен, чтобы команды `/stats` и `/export`
работали только у тебя.

### Шаг 3. Установить Python

Скачай Python 3.11 или новее с [python.org](https://www.python.org/downloads/).

> При установке на Windows обязательно поставь галочку **«Add Python to PATH»**
> на самом первом экране. Без неё команда `python` не будет работать.

Проверить, что всё встало — открой PowerShell и набери:

```
python --version
```

Должно ответить что-то вроде `Python 3.12.4`.

### Шаг 4. Установить библиотеки

Открой PowerShell **в папке `sportbot`** (правой кнопкой по папке →
«Открыть в терминале») и выполни:

```
pip install -r requirements.txt
```

Это займёт минуту. Ставится 5 библиотек: aiogram (сам Telegram), aiosqlite (база),
APScheduler (напоминания), python-dotenv (секреты) и tzdata (часовые пояса).

### Шаг 5. Создать файл .env

Рядом с `bot.py` лежит файл `.env.example` — это образец. Сделай его копию и назови
копию просто `.env` (точка в начале обязательна, расширения нет).

Открой `.env` блокнотом и впиши туда свои значения:

```
BOT_TOKEN=7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
ADMIN_ID=512345678
```

Без кавычек, без пробелов вокруг знака `=`.

> Файл `.env` не выкладывай никуда и не отправляй никому — там твой токен.

## Как запускать и останавливать

### Способ 1: в один щелчок (самый простой)

Найди в папке `sportbot` файл **`run_bot.bat`** и щёлкни по нему два раза.

Откроется чёрное окно, бот запустится. Этот файл сам проверит, что Python на месте,
что есть `.env` с токеном, и при первом запуске сам поставит все библиотеки.
Если чего-то не хватает — напишет понятным текстом, чего именно.

> Совет: щёлкни по `run_bot.bat` правой кнопкой → «Отправить» → «Рабочий стол
> (создать ярлык)». Тогда бот будет запускаться прямо с рабочего стола.

### Способ 2: вручную через PowerShell

В PowerShell, находясь в папке `sportbot`:

```
python bot.py
```

Если всё хорошо, в консоли появится:

```
23:20:08 | INFO  | __main__ | База данных готова
23:20:09 | INFO  | __main__ | Подключено роутеров: 5
23:20:09 | INFO  | __main__ | Планировщик запущен: напоминания и закрытие прошедших игр
23:20:09 | INFO  | __main__ | Бот «TeamUP» (@teamup_school_bot) запущен. Останов — Ctrl+C
```

Теперь открой своего бота в Telegram и отправь `/start`.

**Остановка.** Нажми **Ctrl + C** в окне консоли.

> Важно: пока окно консоли закрыто или компьютер выключен — бот не работает
> и не отвечает никому. Это нормально для школьного проекта: включай его на время,
> когда ребята им пользуются.

При первом запуске рядом с `bot.py` появится файл **`data.db`** — это база данных
со всеми пользователями и играми. Не удаляй его, иначе пропадут все данные.

## Команды бота

| Команда   | Кто может     | Что делает                                  |
|-----------|---------------|---------------------------------------------|
| `/start`  | все           | Знакомство и главное меню                   |
| `/help`   | все           | Короткая справка                            |
| `/admin`  | только ты     | Справка по командам организатора            |
| `/stats`  | только ты     | Цифры для отчёта по проекту                 |
| `/export` | только ты     | Присылает `games.csv` и `signups.csv`       |
| `/games`  | только ты     | Все игры с номерами                         |
| `/who 12` | только ты     | Кто записан на игру №12                     |
| `/delete_game 12` | только ты | Убрать игру №12                        |
| `/reviews` | только ты    | Свежие отзывы об играх                      |
| `/reviews 12` | только ты | Отзывы об игре №12                        |
| `/users`  | только ты     | Список учеников с активностью               |
| `/warn @ник причина` | только ты | Выдать предупреждение              |
| `/warns @ник` | только ты | История предупреждений                     |
| `/clearwarns @ник` | только ты | Стереть предупреждения               |
| `/ban @ник 7 причина` | только ты | Закрыть создание игр на 7 дней   |
| `/unban @ник` | только ты | Снять запрет                               |
| `/admins` | только главный | Список помощников                     |
| `/makeadmin @ник` | только главный | Выдать права помощника        |
| `/removeadmin @ник` | только главный | Забрать права               |

Файлы из `/export` открываются в Excel и Google Таблицах — кодировка и разделитель
подобраны так, чтобы русские буквы не превратились в кракозябры.

## Что делать, если что-то не работает

**`python: не удается найти файл`** или `«python» не является внутренней командой`
— Python не установлен или при установке не была поставлена галочка «Add Python to
PATH». Переустанови Python и поставь галочку.

**`Не найден BOT_TOKEN`** — нет файла `.env` или он лежит не в той папке. Он должен
быть ровно рядом с `bot.py`. Проверь, что файл называется именно `.env`, а не
`.env.txt` (в Windows включи показ расширений файлов, чтобы это увидеть).

**`Telegram не принял этот BOT_TOKEN`** — токен скопирован не полностью или в него
попали пробелы/кавычки. Скопируй строку из @BotFather заново, целиком.

**`Нет связи с Telegram`** — проверь интернет.

**`ModuleNotFoundError: No module named 'aiogram'`** — библиотеки не установились.
Повтори шаг 4, находясь именно в папке `sportbot`.

**Бот не отвечает, а в консоли тихо** — проверь, что окно с `python bot.py` всё ещё
открыто и там нет красных строк. Если закрыл — запусти заново.

**Бот отвечает старыми текстами** — после правки файлов надо остановить бота
(Ctrl + C) и запустить заново. На лету изменения не подхватываются.

**Хочу начать с чистого листа** — останови бота, удали файл `data.db` и запусти
снова. База создастся пустой. Все игры и пользователи при этом пропадут.

## Если будешь выкладывать проект на GitHub

В папке проекта (на уровень выше `sportbot`) лежит файл **`.gitignore`**. Это список
того, что git обязан игнорировать. Он уже настроен и прячет:

- `.env` — твой токен;
- `data.db` — базу с именами и классами учеников;
- `*.csv` — выгрузки из `/export`;
- служебные папки Python.

То есть на GitHub попадёт только код и `.env.example` с пустыми полями. Это правильно:
любой сможет посмотреть, как проект устроен, но не сможет угнать бота.

> Проверить перед первой заливкой: выполни `git status` и убедись, что в списке
> **нет** ни `.env`, ни `data.db`. Если они там есть — значит `.gitignore` лежит не
> в той папке.

## Из чего состоит проект

```
sportbot/
├── run_bot.bat         запуск в один щелчок (Windows)
├── bot.py              запуск бота и планировщика
├── config.py           настройки: токен, админ, списки спорта/мест/времени
├── texts.py            ВСЕ тексты сообщений
├── database.py         таблицы и все функции работы с базой
├── keyboards.py        все клавиатуры и кнопки
├── scheduler.py        напоминания и закрытие прошедших игр
├── handlers/
│   ├── start.py        /start, регистрация, меню, помощь
│   ├── create_game.py  пошаговое создание игры
│   ├── games_list.py   список игр, записаться/отписаться
│   ├── my_games.py     мои игры, отмена игры
│   ├── profile.py      профиль: смена класса и имени
│   └── admin.py        /stats и /export
├── requirements.txt    список библиотек
├── .env.example        образец файла с секретами
├── .env                твои секреты (создаёшь сам, никому не показываешь)
└── data.db             база данных (появляется сама)
```

## Что менять, если захочется

| Хочу...                        | Файл        | Где именно                        |
|--------------------------------|-------------|-----------------------------------|
| Добавить вид спорта            | `config.py` | список `SPORTS` (и `SPORT_EMOJI`) |
| Добавить место                 | `config.py` | список `PLACES`                   |
| Добавить вариант времени       | `config.py` | список `TIMES`                    |
| Другие варианты длительности   | `config.py` | словарь `DURATIONS`               |
| Другие варианты потолка состава| `config.py` | список `MAX_PLAYER_OPTIONS`       |
| Другие варианты числа игроков  | `config.py` | список `PLAYER_COUNTS`            |
| Переименовать бота             | `config.py` | `BOT_NAME`                        |
| Разрешить больше 3 игр         | `config.py` | `MAX_ACTIVE_GAMES`                |
| Показывать больше 10 игр       | `config.py` | `GAMES_LIST_LIMIT`                |
| Поправить любой текст бота     | `texts.py`  | нужная переменная                 |

После любой правки останови бота и запусти заново.
