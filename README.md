# 🏀 TeamUP

**Телеграм-бот, который помогает школьникам собираться на спортивные игры после уроков.**

Социальный проект ученика школы города Астаны.

---

## Проблема

После уроков хочется поиграть в футбол или баскетбол, но собрать команду тяжело.
Нужно обойти знакомых, спросить у каждого, а половина согласившихся потом передумает.
В итоге играют одни и те же ребята из одного класса, а остальные не играют вообще.

## Решение

Один человек создаёт игру за 30 секунд. Остальные видят её и записываются одной
кнопкой. Бот сам считает, сколько человек собралось, сообщает всем, когда команда
готова, и напоминает за час до начала.

Главное — записаться может **любой ученик школы**, а не только друзья организатора.
Поэтому в одной команде оказываются ребята из разных классов. Бот считает это
отдельной метрикой.

---

## Что умеет

- **Создание игры** — пошагово: вид спорта, день, время, место, сколько нужно человек
- **Общий список игр** — карточки ближайших игр с кнопкой «Записаться»
- **Автоматический подсчёт** — когда народу набралось, всем приходит «Команда собрана»
- **Напоминания** — за час до начала бот пишет всем участникам
- **Мои игры** — что ты организуешь и куда записан, с отменой и отпиской
- **Профиль** — своё имя, класс и личная статистика; класс и имя можно менять
- **Статистика** — цифры для отчёта по проекту, доступны только организатору

Так выглядит карточка игры:

```
🏀 Баскетбол
📅 Завтра, 18 августа (вт)
🕒 15:30
📍 Площадка за школой
👥 Записались: 4 из 6
🙋 Организатор: Арман (8Б)

        [ ✅ Записаться ]
```

## Технологии

| Что | Зачем |
|---|---|
| **Python 3.11+** | язык проекта |
| **aiogram 3** | работа с Telegram, асинхронно |
| **SQLite + aiosqlite** | база данных в одном файле, без сервера |
| **APScheduler** | напоминания и закрытие прошедших игр |
| **python-dotenv** | токен и настройки отдельно от кода |

Всё бесплатное и работает локально. Никаких внешних сервисов, облачных баз
и платных подписок.

## Быстрый старт

```bash
git clone https://github.com/n0nam3e01/TeamUPproject.git
cd TeamUPproject/sportbot
pip install -r requirements.txt
```

Дальше нужен токен бота от [@BotFather](https://t.me/BotFather):
скопируй `.env.example` в `.env` и впиши туда токен и свой telegram id.

```bash
python bot.py
```

На Windows можно проще — двойной щелчок по **`run_bot.bat`**.
Он сам проверит Python, при первом запуске поставит библиотеки и запустит бота.

📖 Подробная инструкция для новичка — в [sportbot/README.md](sportbot/README.md)

## Структура

```
sportbot/
├── bot.py              запуск бота и планировщика
├── config.py           настройки: списки спорта, мест, времени
├── texts.py            все тексты сообщений
├── database.py         три таблицы и работа с ними
├── keyboards.py        все кнопки
├── scheduler.py        напоминания и фоновые задачи
├── handlers/
│   ├── start.py        регистрация и главное меню
│   ├── create_game.py  пошаговое создание игры
│   ├── games_list.py   список игр, запись и отписка
│   ├── my_games.py     мои игры, отмена
│   ├── profile.py      профиль: смена класса и имени
│   └── admin.py        статистика и выгрузка
└── run_bot.bat         запуск в один щелчок (Windows)
```

Три таблицы в базе: `users` (кто пользуется), `games` (созданные игры),
`signups` (кто на что записался).

## Метрики проекта

Команда `/stats` доступна только организатору и считает:

- всего пользователей и распределение по классам
- игр создано, состоялось, отменено
- уникальных участников
- средний размер команды
- самый популярный вид спорта
- **сколько человек хотя бы раз играли в одной команде с учеником из другого класса**

Последняя цифра — ключевая для проекта. Ради неё всё и затевалось.

Команда `/export` выгружает данные в два CSV-файла для отчёта.

## Безопасность и приватность

- Бот хранит только telegram id, имя, ник и класс — ничего лишнего
- Токен лежит в файле `.env`, который **не попадает в репозиторий**
- База `data.db` с данными учеников тоже не выкладывается
- За это отвечает [`.gitignore`](.gitignore)

В репозитории лежит только код и `.env.example` с пустыми полями.
